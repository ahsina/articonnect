- Constat : compliance/ n'expose qu'un KYC controller (compliance/kyc, GET status/:userId admin). L'export/suppression RGPD existe en self-service utilisateur mais AUCUN endpoint ni page admin ne recense/traite les demandes des personnes concernées.
- ➡️ GAP : Pas de file/registre admin des demandes RGPD (droit d'accès/effacement/portabilité) ni de journal de traitement dans les délais. Devrait vivre dans un compliance/data-requests controller + page admin/admin/compliance-requests. Impact : conformité RGPD opérationnelle non outillée pour l'opérateur.

- ➡️ GAP : Lien mort/404 : le client connecté qui reçoit un devis formel n'a pas d'inbox in-app pour le lister/consulter/accepter/signer.
